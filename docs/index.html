Quick Start

Get up and running with WibeChat in 5 steps. Choose your platform to see tailored instructions.

Install the SDK

Install the WibeChat React SDK. The core client (@wibechat/core) is included automatically as a dependency.

bash
npm install @wibechat/react

Set your API key

Add your chat and video keys to .env.local. You get them from the WibeChat Admin Portal.

.env.local
NEXT_PUBLIC_WIBECHAT_CHAT_KEY=wb_chat_xxxxxxxxxxxx
NEXT_PUBLIC_WIBECHAT_VIDEO_KEY=wb_video_xxxxxxxxxxxx
NEXT_PUBLIC_LIVEKIT_URL=wss://call.wibechat.com

Wrap your app with WibeChatProvider

The provider initializes the SDK client and provides context to all child components. Import the styles CSS for pre-built component styling.

app/layout.tsx
import { WibeChatProvider } from '@wibechat/react';
import '@wibechat/react/styles.css';

export default function RootLayout({ children }) {
  return (
    <WibeChatProvider
      apiKey={process.env.NEXT_PUBLIC_WIBECHAT_CHAT_KEY}
    >
      {children}
    </WibeChatProvider>
  );
}

Add a chat window

Drop in a fully-featured chat UI with channels, messages, and input — all in one component.

components/Chat.tsx
import { ChatWindow } from '@wibechat/react';

export default function Chat() {
  return (
    <ChatWindow
      defaultChannel="general"
      height="600px"
      showChannelList
    />
  );
}

Add a call button

First, install the LiveKit UI packages for the call interface:

bash
npm install @livekit/components-react @livekit/components-styles

Then generate a LiveKit token and launch a call room. Use with @livekit/components-react for the call UI.

components/Call.tsx
import { useState } from 'react';
import { CallButton, WibeChatProvider } from '@wibechat/react';
import { LiveKitRoom, VideoConference } from '@livekit/components-react';
import '@livekit/components-styles';

export default function Call() {
  const [callState, setCallState] = useState(null);

  if (callState) {
    return (
      <LiveKitRoom
        token={callState.token}
        serverUrl={callState.serverUrl}
        onDisconnected={() => setCallState(null)}
        video
        audio
        data-lk-theme="default"
      >
        <VideoConference />
      </LiveKitRoom>
    );
  }

  // Calls need your video key, so CallButton gets its own provider.
  return (
    <WibeChatProvider apiKey={process.env.NEXT_PUBLIC_WIBECHAT_VIDEO_KEY}>
      <CallButton
        room="standup-room"
        identity="alice@example.com"
        name="Alice"
        livekitServerUrl={process.env.NEXT_PUBLIC_LIVEKIT_URL}
        onTokenGenerated={(token, serverUrl, room) => {
          setCallState({ token, serverUrl, room });
        }}
      />
    </WibeChatProvider>
  );
}

Install the SDK

Install the WibeChat Python SDK from PyPI. Version 0.5.0 or later uses your dashboard keys.

bash
pip install "wibechat>=0.5.0"

Set your API keys

Add your chat and video keys from the WibeChat dashboard (Profile → API Credentials) to a .env file or your environment.

.env
WIBECHAT_CHAT_API_KEY=wb_chat_xxxxxxxxxxxx
WIBECHAT_API_KEY=wb_video_xxxxxxxxxxxx

Initialize the chat client

Create a WibechatChat instance with your chat key.

main.py
from wibechat import WibechatChat

chat = WibechatChat(api_key="wb_chat_xxxxxxxxxxxx")

Send a message

Send to a channel, or directly to a user.

main.py
# Send to a channel
chat.send_message(
    to="general",
    content="Hello from the Python SDK!",
    topic="greetings",
)

# Send a direct message
chat.send_direct_message(
    to="alice@example.com",

Generate a call token

Calls use your video (or audio) key. The token comes with the LiveKit server URL to connect to.

main.py
from wibechat import WibechatClient

client = WibechatClient(api_key="wb_video_xxxxxxxxxxxx")

token = client.get_token(
    room_name="standup-room",
    user_identity="alice@example.com",
    user_name="Alice",
    ttl_seconds=3600,
)

print(token.access_token)  # Pass to the client
print(token.server_url)    # wss://call.wibechat.com

Authentication

WibeChat issues one API key per service: chat, audio and video. All API requests require an Authorization: Bearer header. Call tokens are generated via the SDK.

API Key

The WibeChat Admin Portal shows one API key for each service your organization has enabled. Use the chat key for /chat/ and events endpoints, and the audio or video key for /calls/ endpoints. A key used on another service's endpoints gets 403 Forbidden.

Key PrefixExampleDescription
wb_chat_wb_chat_a1b2c3d4e5f6Chat: channels, messages, users, presence, files, real-time events
wb_audio_wb_audio_a1b2c3d4e5f6Audio calls: call tokens and rooms
wb_video_wb_video_a1b2c3d4e5f6Video calls: call tokens and rooms
One client per key

A WibeChatClient or WibeChatProvider holds one key. To use chat and calling in the same app, create one for each: for example, a provider with your chat key around chat components and another with your video key around CallButton.

Python SDK

The Python SDK (pip install "wibechat>=0.5.0") uses the same dashboard keys: your chat key for WibechatChat and your video or audio key for WibechatClient. Versions before 0.5.0 used a chat account's email and API key and an lk_ calling license key; those still work if you already have them.

Using the API Key

All requests to the WibeChat gateway require the API key in the Authorization header.

TypeScript
import { WibeChatClient } from '@wibechat/core';

// The SDK handles auth headers automatically
const client = new WibeChatClient({
  apiKey: 'wb_chat_xxxxxxxxxxxx',
});

// Or use the React provider (handles it for you)
<WibeChatProvider apiKey="wb_chat_xxxxxxxxxxxx">
  {children}
</WibeChatProvider>
TypeScript
// All API requests use Bearer token auth
const response = await fetch('https://api.chat.zartek.in/api/gateway/chat/channels/', {
  headers: {
    'Authorization': 'Bearer wb_chat_xxxxxxxxxxxx',
    'Content-Type': 'application/json',
  },
});
Python
from wibechat import WibechatChat, WibechatClient

# Chat uses your wb_chat_ key
chat = WibechatChat(api_key="wb_chat_xxxxxxxxxxxx")

# Calling uses your wb_video_ (or wb_audio_) key
client = WibechatClient(api_key="wb_video_xxxxxxxxxxxx")

# Or read them from WIBECHAT_CHAT_API_KEY and WIBECHAT_API_KEY
chat = WibechatChat()
client = WibechatClient()
JavaScript
import { WibeChatClient } from '@wibechat/core';

// The SDK handles auth headers automatically
const client = new WibeChatClient({
  apiKey: 'wb_chat_xxxxxxxxxxxx',
});

// Or use raw HTTP with Bearer token
const res = await fetch('https://api.chat.zartek.in/api/gateway/chat/channels/', {
  headers: { 'Authorization': 'Bearer wb_chat_xxxxxxxxxxxx' },
});

Call Room Tokens

LiveKit call rooms require a JWT access token. Generate one using client.calls.createToken().

TypeScript
import { WibeChatClient } from '@wibechat/core';

const client = new WibeChatClient({ apiKey: 'wb_video_xxxxxxxxxxxx' });

// Generate a LiveKit token
const token = await client.calls.createToken({
  room: 'standup-room',
  identity: 'alice@example.com',
  name: 'Alice',
  ttl: 3600,  // 1 hour (60–86400 seconds)
});

// Pass this token to LiveKitRoom or the CallButton component
Token security

The wb_chat_ API key is a publishable key — it's safe to use in client-side code (similar to Stripe's publishable key). Call tokens are short-lived JWTs generated through the WibeChat gateway. For additional security, you can proxy API calls through your backend.

Chat Integration

Embed full-featured messaging in your application: channels, messages, users, presence, and file uploads.

Pre-built components vs hooks

Use pre-built components (<ChatWindow>, <ChannelList>, <MessageList>) for the fastest integration. Use hooks (useChannels, useMessages) when you need full control over the UI or want to build custom interfaces.

Channels

Channels are group conversations. List, create, and select channels using the useChannels hook or pre-built components.

components/ChannelSidebar.tsx
import { ChannelList, useChannels } from '@wibechat/react';

// Option 1: Pre-built component
export default function Sidebar() {
  return (
    <ChannelList
      onChannelSelect={(name) => console.log(`Selected: ${name}`)}
    />
  );
}

// Option 2: Hook for custom UI
function CustomChannelList() {
  const { channels, loading, error, refetch } = useChannels();

  if (loading) return <p>Loading...</p>;
  if (error) return <p>Error: {error.message}</p>;

  return (
    <ul>
      {channels.map(ch => (
        <li key={ch.stream_id}>#{ch.name}</li>
      ))}
    </ul>
  );
}
channels.py
from wibechat import WibechatChat

chat = WibechatChat()  # uses WIBECHAT_CHAT_API_KEY

# List all channels
for s in chat.get_streams():
    print(f"#{s.name} (id={s.id}) — {s.description}")

# Create a channel
chat.create_channel(name="engineering", description="Engineering team")
JavaScript
const channels = await client.chat.getChannels();
channels.forEach(ch => console.log(`#${ch.name}`));

Messages

Fetch message history with infinite scroll and send new messages using the useMessages hook.

components/Messages.tsx
import { useMessages, MessageList, MessageInput } from '@wibechat/react';

// Option 1: Pre-built components
function ChatView({ channel }) {
  return (
    <div>
      <MessageList channel={channel} />
      <MessageInput channel={channel} placeholder="Type a message..." />
    </div>
  );
}

// Option 2: Hook for custom UI
function CustomMessages({ channel }) {
  const {
    messages, loading, hasMore,
    loadMore, sendMessage,
  } = useMessages({ channel, pageSize: 50 });

  return (
    <div>
      {hasMore && <button onClick={loadMore}>Load older</button>}
      {messages.map(msg => (
        <div key={msg.id}>
          <strong>{msg.sender_full_name}</strong>: {msg.content}
        </div>
      ))}
      <button onClick={() => sendMessage('Hello!')}>Send</button>
    </div>
  );
}

Users & Presence

Show online/idle/offline status for users in your organization.

components/UserSidebar.tsx
import { UserList, useUsers, usePresence } from '@wibechat/react';

// Option 1: Pre-built component with presence indicators
<UserList />

// Option 2: Hooks for custom UI
function OnlineUsers() {
  const { users, loading } = useUsers();
  const { presences } = usePresence();

  return (
    <ul>
      {users.map(user => {
        const status = presences[user.email]?.aggregated?.status ?? 'offline';
        return (
          <li key={user.user_id}>
            {user.full_name} — {status}
          </li>
        );
      })}
    </ul>
  );
}

File Uploads

Upload files and include them in messages.

components/FileUpload.tsx
import { useChat } from '@wibechat/react';

function FileUploader() {
  const client = useChat();  // returns the WibeChatClient instance

  const handleUpload = async (file) => {
    // Upload a file
    const { uri } = await client.chat.uploadFile(file);

    // Send a message with the file link
    await client.chat.sendMessage({
      to: 'general',
      content: `Shared a file: [${file.name}](${uri})`,
      topic: 'files',
    });
  };

  return <input type="file" onChange={e => handleUpload(e.target.files[0])} />;
}

Calling Integration

Add voice and video calls powered by LiveKit. WibeChat generates access tokens and manages rooms — you bring the LiveKit UI components.

LiveKit dependency

Calling features require @livekit/components-react and @livekit/components-styles for the React call UI. WibeChat handles token generation and room management; LiveKit handles the actual audio/video rendering. Install them with: npm install @livekit/components-react @livekit/components-styles

CallButton Component

The simplest way to add calling. Generates a LiveKit token on click and fires a callback with the token and server URL. Wrap it in a WibeChatProvider that holds your video (or audio) key, since the chat key cannot create call tokens. Set livekitServerUrl to your LiveKit server URL: the component passes it to the callback as serverUrl, and it is empty if you leave the prop out.

components/VideoCall.tsx
import { useState } from 'react';
import { CallButton, WibeChatProvider } from '@wibechat/react';
import { LiveKitRoom, VideoConference } from '@livekit/components-react';
import '@livekit/components-styles';

export default function VideoCall() {
  const [callState, setCallState] = useState(null);

  if (callState) {
    return (
      <LiveKitRoom
        token={callState.token}
        serverUrl={callState.serverUrl}
        onDisconnected={() => setCallState(null)}
        video
        audio
        data-lk-theme="default"
      >
        <VideoConference />
      </LiveKitRoom>
    );
  }

  // Calls need your video key, so CallButton gets its own provider.
  return (
    <WibeChatProvider apiKey={process.env.NEXT_PUBLIC_WIBECHAT_VIDEO_KEY}>
      <CallButton
        room="standup-room"
        identity="alice@example.com"
        name="Alice"
        label="Join Call"
        livekitServerUrl={process.env.NEXT_PUBLIC_LIVEKIT_URL}
        onTokenGenerated={(token, serverUrl, room) => {
          setCallState({ token, serverUrl, room });
        }}
      />
    </WibeChatProvider>
  );
}

useCallToken Hook

For more control, use the useCallToken hook to generate tokens programmatically. Like CallButton, it must be inside a WibeChatProvider that holds your video or audio key.

hooks/useCall.ts
import { useCallToken } from '@wibechat/react';
import { LiveKitRoom, VideoConference } from '@livekit/components-react';

function CustomCallUI() {
  const { token, loading, error, generateToken } = useCallToken();

  const joinCall = async () => {
    const t = await generateToken({
      room: 'standup-room',
      identity: 'alice@example.com',
      name: 'Alice',
      ttl: 3600,
    });
    // t is the JWT token string — pass to LiveKitRoom
  };

  if (token) {
    return (
      <LiveKitRoom token={token} serverUrl="wss://call.wibechat.com">
        <VideoConference />
      </LiveKitRoom>
    );
  }

  return <button onClick={joinCall} disabled={loading}>Join Call</button>;
}

Room Management

Create and list call rooms using the core client. Use it inside a WibeChatProvider that holds your video or audio key.

components/RoomManager.tsx
import { useChat } from '@wibechat/react';

function RoomManager() {
  const client = useChat();  // the provider's client: must hold a call key

  const createRoom = async () => {
    const room = await client.calls.createRoom({
      name: 'standup-room',
      max_participants: 10,
      empty_timeout: 300,  // auto-close after 5 min empty
    });
    console.log(`Created: ${room.name} (${room.sid})`);
  };

  const listRooms = async () => {
    const rooms = await client.calls.listRooms();
    rooms.forEach(r =>
      console.log(`${r.name}: ${r.num_participants} participants`)
    );
  };
}

Real-time Events

Subscribe to live events via Server-Sent Events (SSE) for messages, typing indicators, presence changes, and more.

Connecting

Enable real-time events either via the provider prop or manually via the client.

TypeScript
// Option 1: Via the provider (auto-connects on mount)
<WibeChatProvider
  apiKey="wb_chat_xxxxxxxxxxxx"
  connectRealTime={true}
>
  {children}
</WibeChatProvider>

// Option 2: Manual connection via core client
const client = new WibeChatClient({ apiKey: 'wb_chat_xxxxxxxxxxxx' });
client.connectRealTime();

Event Types

Subscribe to specific event types using client.events.on(). Each subscription returns an unsubscribe function.

EventPayloadDescription
message{ message: Message }New message received
update_message{ message_id, content?, subject? }Message edited
delete_message{ message_id, message_type }Message deleted
typing{ op: 'start'|'stop', sender: { user_id, email } }Typing indicator
presence{ user_email, presence: { status, timestamp } }User online/idle/offline
channel_created{ channel: { stream_id, name, description } }New channel created
channel_deleted{ channel: { stream_id, name, description } }Channel deleted
reaction{ op: 'add'|'remove', message_id, emoji_name, user_id }Reaction added/removed
heartbeat{}Keep-alive signal
TypeScript
import { useChat } from '@wibechat/react';
import { useEffect } from 'react';

function RealtimeListener() {
  const client = useChat();

  useEffect(() => {
    // Subscribe to new messages
    const unsubMsg = client.events.on('message', (event) => {
      console.log('New message:', event.payload.message.content);
    });

    // Subscribe to typing events
    const unsubTyping = client.events.on('typing', (event) => {
      const { op, sender } = event.payload;
      console.log(`${sender.email} ${op === 'start' ? 'is typing...' : 'stopped typing'}`);
    });

    // Subscribe to presence changes
    const unsubPresence = client.events.on('presence', (event) => {
      const { user_email, presence } = event.payload;
      console.log(`${user_email} is ${presence.status}`);
    });

    // Monitor connection state
    const unsubState = client.events.onStateChange((state) => {
      console.log('Connection:', state);
      // 'disconnected' | 'connecting' | 'connected' | 'reconnecting'
    });

    return () => {
      unsubMsg();
      unsubTyping();
      unsubPresence();
      unsubState();
    };
  }, [client]);

  return null;
}
Auto-reconnect

The SSE connection automatically reconnects with exponential backoff (3s to 60s cap) if the connection drops. You don't need to handle reconnection logic manually.

API Reference

REST API endpoints for direct integration. Base URL: https://api.chat.zartek.in

Authentication

All API requests require an Authorization header: Authorization: Bearer wb_chat_xxxxxxxxxxxx. Chat and event endpoints take your wb_chat_ key; calling endpoints take your wb_audio_ or wb_video_ key.

Error Responses

Errors come back as JSON. Authentication and permission errors use {"detail": "message"}; validation errors list the problem per field, for example {"content": ["This field is required."]}; errors from the chat or calling servers use {"error": "message"}. Common status codes: 400 Bad Request, 401 invalid or missing key, 403 key is for another service or the service is disabled, 404 Not Found, 429 Rate Limited, 503 calling not configured for your organization.
